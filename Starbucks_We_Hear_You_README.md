# Starbucks "We Hear You" Campaign

### Master's Project

This repository contains my master's project in which I developed a mock
integrated marketing campaign for Starbucks titled *"We Hear You."* The
project explores brand perception, customer engagement, and strategic
communication through a research-driven campaign concept.

The original academic submission has been expanded into a multi-format
portfolio. Using NotebookLM, I transformed the research and strategy
into additional presentation, visual, and audio formats to demonstrate
AI-assisted content adaptation and workflow integration.
